# OS-Project-xMeine

## Network Cable Demo - Computer Networks Educational Game

Network Cable Demo is an educational mobile game prototype designed to teach basic computer networking concepts through simple and interactive gameplay. The project focuses on helping beginner students understand networking topics such as Ethernet connection, IP address selection, gateway, DNS, Wi-Fi signal, packets, and firewall rules through daily-life scenarios.

This project is developed as a Computer Networks course milestone project.

## Project Idea

Many students learn computer networks through abstract definitions. This project aims to make these concepts easier to understand by turning them into small playable tasks.

Instead of only explaining that a computer needs a physical connection or an IP address, the game shows these concepts through actions:

- Dragging an Ethernet cable to the modem port
- Selecting a compatible IP address for the local network
- Understanding why a gateway is needed
- Learning how DNS translates website names into IP addresses

The main goal is not to replace theoretical lessons, but to help students build intuition before studying formal networking topics.
